3. LAYER 2 CONFIGURATION IMPLEMENTED
======================================================================

TEXTURE_MAP_2D Layer 2 now contains exactly three selectable rows:

    [1] PREVIEW PARTICLE RADIUS
    [2] PIXEL GRID
    [3] RUN WORKSPACE EDIT

W and S wrap across all three rows.

Row [1] - PREVIEW PARTICLE RADIUS
---------------------------------

Default:

    0.0098

The previous free-running radius adjustment was replaced by the
required discrete preset family:

    0.0039
    0.0046
    0.0054
    0.0061
    0.0068
    0.0076
    0.0083
    0.0091
    0.0098
    0.0105
    0.0113
    0.0120
    0.0127
    0.0135
    0.0142
    0.0149
    0.0156

A selects the previous preset.
D selects the next preset.
The list clamps at the minimum and maximum and does not wrap.
E and Enter perform no action on this row.

While Row [1] is selected, the renderer displays the existing cyan
wireframe collision-radius sphere around the textured particle.

Row [2] - PIXEL GRID
--------------------

Default:

    64 x 64

The available logical editing resolutions are:

    32 x 32
    64 x 64
    128 x 128

A and D cycle this list with wrapping.

The value is retained in TextureMapTargetContext::pixelGridDivisions.
It does not resize the 1024 x 1024 source texture and does not create
pixel cells, canvas geometry, UV guides, or painting behavior.

E and Enter perform no action on this row.

Row [3] - RUN WORKSPACE EDIT
----------------------------

A and D perform no action.

E or Enter emits a lightweight Arbiter intent requesting the Layer 3
transition. TheArbiter does not load, inspect, upload, or mutate assets.

======================================================================
4. LAYER 3 TRANSITION IMPLEMENTED
======================================================================

EuclidEngine validates the Layer 2 to Layer 3 transition.

Entry is allowed only when:

    target.loaded == true

    target.assetId != INVALID_ASSET_ID

    target.readiness == TextureTargetReadiness::Ready

    the canonical StaticParticleAsset still exists in the shared
    ProjectAssetRepository

    EuclidRenderer is available and can refresh the canonical asset

If validation fails, the application remains in Layer 2 and prints a
specific diagnostic. Navigation changes only after validation and the
renderer refresh have succeeded.

The engine-confirmed Arbiter transition enters:

    ApplicationLayer::ACTIVE_WORKSPACE
    WorkspaceDomain::GRID_2D
    WorkspaceId::TEXTURE_MAP_2D
